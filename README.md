# Employee Management SQL Database

## 📌 Project Overview
This project demonstrates basic SQL operations by creating an Employee Management database. It stores employee information such as employee ID, name, department, age, salary, and email.

## 🛠️ Technologies Used
- MySQL
- SQL (DDL & DML)

## 📂 Database Structure

| Column | Data Type |
|---------|-----------|
| Emp_ID | INT |
| Emp_Name | VARCHAR |
| Department | VARCHAR |
| Age | INT |
| Salary | DECIMAL(10,2) |
| Mail_ID | VARCHAR |

## Features
- Create Employee table
- Insert employee records
- Store department, salary, and email
- View employee details using SELECT queries
